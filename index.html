      Settings

      Finnhub's free tier doesn't expose a market-wide "trending" discovery list — that's a premium screener feature. This ranks the symbols you already track (watchlist + indices) by how far they've moved, live once you add a key below.

      TAPE runs on simulated data by default so it always works. Paste a free API key from finnhub.io to pull real quotes and headlines instead. The key is stored only for you, in this artifact's storage — never shared.

      The options-flow panel is simulated by default too. Real flow alerts (sweeps, blocks, repeated hits) come from Unusual Whales' API, which is a paid product — there's no free tier for this data, since it's built on the live options tape. Only add a key if you already have one.
